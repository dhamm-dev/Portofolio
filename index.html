LoopLink

A collaborative local waste exchange connecting people with materials to those who can reuse them.

NEXT.JS / SUPABASE
Project details

LoopLink is a collaborative project for a local materials exchange. It connects people who have waste materials with others looking for reusable resources nearby.

Users can create listings and search by category and distance. Image classification helps suggest a category, while users retain the ability to review and correct the result. The project explores how software can make local reuse easier to discover.

Dhexx Panel

A PHP hosting panel for managing projects, files, databases, and deployments.

PHP / SQLITE / MYSQL
Project details

I built Dhexx Panel to make my home server easier to manage. After trying aaPanel and finding that many features were paid, I wanted a panel focused on the tasks I needed.

The PHP panel brings together projects, files, databases, system information, and logs. Its repository also documents Git-based deployment through a worker and webhook.

07 / WEB APP

WA Dashboard

A personal dashboard for managing WhatsApp accounts, contacts, and scheduled messages.

NODE.JS / JAVASCRIPT
Project details

I built WA Dashboard after getting tired of sending the same assistantship schedule to students every week. Existing scheduling tools were often paid, and I was concerned about sharing my chat data with third-party services.

The personal, single-admin dashboard manages multiple WhatsApp accounts and lets me send or schedule messages. It uses an unofficial WhatsApp protocol, so its connection depends on changes to that protocol.

Palmustaka Publisher

A publisher profile and book catalogue with ordering through WhatsApp.

HTML / CSS / JS
Project details

Palmustaka Publisher is a company profile and book catalogue for an independent publisher. Visitors can browse books by category, learn about the publisher, and find manuscript submission guidance.

Book orders are directed to WhatsApp, giving visitors a straightforward way to contact the publisher without a built-in checkout system.

EduKita

A collaborative e-learning project with courses, quizzes, and browser-based storage.

HTML / CSS / JS
Project details

EduKita is a collaborative e-learning prototype built for a web programming course. It brings together course catalogues, learning materials, quizzes, and separate views for students, instructors, and administrators.

By keeping its data in browser localStorage, the project demonstrates learning-platform workflows without a server or database. It is a prototype rather than a production learning service.
