# Dhamm-Dev | Portfolio

**Curious mind. Making things for the web.**

I'm Idham Kholid Abidin, an Informatics Engineering student who likes making everyday tasks easier. This portfolio is a collection of projects shaped by curiosity, practical problems, and the things I wanted to build for myself.

## The thinking behind the tools

Some of my favorite projects started with a small frustration:

- [LAMPP Manager](https://github.com/dhamm-dev/lampp-manager-by-dhexx) gives me a web interface for managing local projects and controlling Apache and MySQL on Linux.
- [Dhexx Panel](https://github.com/dhamm-dev/Webserver-Management-dhexx) brings the tools I need to manage my home server into one place.
- [WA Dashboard](https://github.com/dhamm-dev/wa-dashboard) helps me schedule repetitive messages, including weekly assistantship schedules.
- [LoopLink](https://github.com/rofal-gg/LoopLink) is a collaborative project connecting people with reusable materials in their local area.

More projects, their stories, and links are available in the portfolio.

## About this portfolio

The site is built with **HTML, CSS, and vanilla JavaScript**, with an editorial-inspired design in charcoal, warm gray, and burgundy.

- An interactive slide-to-enter introduction
- Project filters and expandable project details
- A little about me, my education, and the tools I use
- A downloadable CV and links to GitHub and Instagram
- Responsive layouts and reduced-motion support
