# Portfolio | Idham Kholid Abidin

A personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview

Open `index.html` in a browser. An internet connection is needed to load the optional Google Fonts; system font fallbacks are provided.

## Editing

- `index.html`: page content, project links, and contact links.
- `style.css`: colors, layout, typography, responsive styles, and reveal transitions.
- `script.js`: scroll reveal using Intersection Observer, with reduced-motion support.
- `profile.jpg`: profile photo.

The project covers use typography. The contact links lead to GitHub and Instagram; there is no message form or backend.
